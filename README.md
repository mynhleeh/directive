# Directive

Welcome to the **Directive** repository. This project serves as a structured Second Brain and Knowledge Base, optimized for both human reading and AI Agent reference.

## 🗂️ Master Index

Below is the directory structure. Each folder is categorized by its resource type.

### Core Assets
*   **[skills/](./skills/)**: Root folder containing distilled AI skills (e.g., `skill-forge`) and external reference skills (e.g., `andrej-karpathy`, `anthropics`).
*   **[rules/](./rules/)**: Global behavioral guidelines, formatting constraints, and persona definitions for agents.
*   **[scripts/](./scripts/)**: Automation scripts (Python, Bash) used to fetch data, compile markdown, or validate structures.

### Reference Knowledge
*   **[guides/](./guides/)**: Finalized, high-level documentation and manuals (e.g., PDF guides for building skills).
*   **[raw-prompts/](./raw-prompts/)**: Raw, unrefined prompt leaks or collections (e.g., `system_prompts_leaks`).
*   **[concepts/](./concepts/)**: Theoretical knowledge, architecture overviews, and mental models (e.g., `system-prompts-and-models-of-ai-tools`).
*   **[architecture/](./architecture/)**: System design documents and architectural blueprints.
*   **[articles/](./articles/)**: Saved webpages, blog posts, or markdown notes.
*   **[papers/](./papers/)**: Academic papers or technical reports.

---

> **Note to AI Agents**: When searching for specific context or references, use this file to navigate to the appropriate subdirectory. Most reference files contain YAML frontmatter (metadata) to aid in semantic search and categorization.
